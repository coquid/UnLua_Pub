# 게임 기획

## 🎮 게임 컨셉
**장르**: 캐주얼 수집 게임
**핵심 재미요소**:
- 맵을 돌아다니며 큐브를 찾아 수집하는 탐험의 재미
- 모든 큐브를 빠르게 찾는 달성감과 도전

**목표 플레이 시간**: 3-5분 (1게임당)
**타겟 플랫폼**: PC

**게임 목표**:
- 맵에 흩어진 모든 큐브를 수집하기
- 가능한 한 빠른 시간 내에 모든 큐브 수집 완료

## 🔧 핵심 기능

### 필수 기능 (MVP - Minimum Viable Product)
1. **플레이어 캐릭터**
   - 기본 이동 (WASD)
   - 마우스 시점 제어
   - Blueprint: `BP_Player`
   - Lua: `BP_Player_C.lua`
   - 기능: WASD 입력 처리, 마우스 회전, 이동 로직

2. **수집 시스템**
   - 큐브-플레이어 충돌 감지
   - 큐브 수집 시 제거
   - Blueprint: `BP_Cube`
   - Lua: `BP_Cube_C.lua`
   - 기능: 충돌 이벤트, 수집 처리, 데이터 업데이트

3. **UI 시스템**
   - 점수 표시 (수집한 큐브 개수)
   - 게임 완료 화면
   - Blueprint: `WBP_GameHUD`, `WBP_GameComplete`
   - Lua: `WBP_GameHUD_C.lua`, `WBP_GameComplete_C.lua`

4. **게임 관리**
   - 게임 시작/완료 관리
   - 승리 조건 체크
   - Blueprint: `BP_GameManager`
   - Lua: `BP_GameManager_C.lua`
   - 기능: 큐브 개수 추적, 완료 조건 확인, 게임 상태 관리

5. **레벨/환경**
   - 기본 게임 맵 (평면 + 경계)
   - 10개의 큐브 배치
   - Blueprint: `BP_Level`
   - 기능: 맵 경계, 큐브 스폰 포인트

## 🛠️ 기술 요구사항

### Blueprint 구조
- **BP_GameManager**: 게임 전체 상태 관리
- **BP_Player**: 플레이어 이동 및 입력 처리
- **BP_Cube**: 수집 가능한 큐브 오브젝트
- **WBP_GameHUD**: 게임 중 UI 표시
- **WBP_GameComplete**: 게임 완료 UI

### Lua Scripts 역할
- **게임 로직**: 큐브 수집 카운팅, 승리 조건 체크
- **이벤트 처리**: 큐브-플레이어 충돌 감지
- **UI 업데이트**: 점수 표시, 완료 화면 표시
- **입력 처리**: WASD 이동, 마우스 회전

### Input 설정 (Legacy Input 시스템)
- **Axis Mappings**: MoveForward (WS), MoveRight (AD), Turn (마우스X), LookUp (마우스Y)
- **Lua 바인딩**: UnLua 자동 바인딩 (함수명 기반)
- **설정 위치**: Config/DefaultInput.ini

### 필요한 에셋
- **큐브**: 기본 큐브 메시 + 머티리얼
- **플레이어**: 기본 캐릭터 또는 캡슐
- **맵**: 평면 바닥 + 경계 벽
- **UI**: 기본 텍스트 위젯
